# IPv6 Extension Test 1

- NID: 100
- PX: 100
- SK: 100
- ODCT: 100
- payload size: 1000 Bytes

## Files
- `config-br`: BR's configuration file
- `run-br.sh`: script that launches BR
- `config-gen.py`: script that generates pcap files and BR's configuration file
- `test3.cfg`: pktgen command-line argument
- `lua/test3.lua`: pktgen configurations including MAC/IP addresses of ports, test execution script, result recording script
- `lua/i*.lua`, `lua/o*.lua`: scripts used by pktgen, one lua script per pktgen run
    - `igp2rm`: inbound GET packet that should be forwarded to RM
    - `ogp2br`: outbound GET packet to BR
    - `idp2br`: inbound DATA packet that should be forwarded to BR
- `pcap/`: containing pcap files loaded by pktgen, `pcap/` is generated by script `config-gen.py`
- `result3.txt`: result generated by running `test3.cfg`

## Hardware Requirements
Computer A and computer B. Both of them are equipped with at least two physical network interfaces. 

## Software Requirements
1. Linux (can run DPDK applications) is installed on both A and B.
2. `br`: border router program installed on computer A
3. `pktgen`: traffic generator installed on computer B
4. `scapy`, `color_packet`: python modules installed on computer B

## Steps
1. Connect port 4 of A to port 4 of B. Connect port 5 of A to port 5 of B.
2. Run script `config-gen.py` on B. A directory named `pcap/` and a file `config-br` will be generated.
3. On computer A, execute command:
```
sudo -H -u zeusnet sh -c "./build-x64.sh"
./build/br-pipeline0 -c 0x0f --log-level 6 -- -p 0x3F --config-file ./config-br
```
4. On computer B, execute command:
```
cd pktgen
./run.py test3
```
5. Result is recorded in file `result3.txt`
